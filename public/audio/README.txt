DROP YOUR BACKGROUND MUSIC HERE
===============================

File name expected by src/data/wedding.js:

    nadaswaram.mp3

Where to get a track:
  - Search for "nadaswaram royalty free" or "thavil instrumental" on
    sites such as Pixabay Audio, Free Music Archive or YouTube Audio Library.
  - Keep it instrumental, 60-90 seconds, under ~1.5 MB so the invitation
    still loads fast on mobile data. Looping is handled automatically.

How to disable music completely:
  In src/data/wedding.js set  music = { src: '', label: '...' }
  The play/mute button hides itself when src is empty.
